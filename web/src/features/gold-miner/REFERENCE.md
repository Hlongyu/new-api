# Gold Miner Reference

Gameplay constants, level layouts, screen flow, fonts, and PNG artwork were
adapted from
[GoldMiner-Rebirth](https://github.com/zzxzzk115/GoldMiner-Rebirth) by Lazy_V,
which is distributed under the MIT License. The referenced assets are stored in
`web/public/gold-miner/assets`.

The browser game engine and React integration were created for this project.
Audio assets are not included.
